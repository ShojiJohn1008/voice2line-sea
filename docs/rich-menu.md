# リッチメニュー設計

このBotは、LIFF画面を前面に出すよりも、LINEトーク上で「文字で記録」「音声で記録」を選べる見た目にする方が使いやすいです。

投稿は「学んだこと」「できなかったこと」「次やりたいこと」に加えて、「モヤモヤしたこと」も残せます。違和感、納得できなかった場面、まだ言語化しきれない引っかかりも、そのまま送ってよい運用にします。

## 推奨フロー

```text
リッチメニュー
  ├─ 文字で記録 → 「そのまま文章を送ってください」と案内 → ユーザーが文章送信 → 分類 → Sheets保存
  ├─ 音声で記録 → 「LINEのマイクからボイスメッセージを送ってください」と案内 → ユーザーが音声送信 → Azure Speechで文字起こし → 分類 → Sheets保存
  └─ 一覧を見る → 「一覧」メッセージ送信 → 直近7日を返信
```

LINEのリッチメニュー自体からスマホの録音を直接開始することはできません。リッチメニューは「メッセージ送信」「URL/LIFFを開く」「postback」などの入口です。音声入力はLINE標準のボイスメッセージを使う形にします。

## ユーザー体験

### 文字で記録

1. ユーザーがリッチメニューの `文字で記録` を押す。
2. Botが案内を返す。
3. ユーザーが普通に文章を送る。
4. Botが分類してスプレッドシートへ保存する。
5. Botが確認を返す。

### 音声で記録

1. ユーザーがリッチメニューの `音声で記録` を押す。
2. Botが「LINEのマイクからボイスメッセージを送ってください」と案内する。
3. ユーザーがLINE標準のボイスメッセージを送る。
4. Botが音声ファイルを取得する。
5. Azure Speechで日本語文字起こしする。
6. LLMで整形・分類する。
7. スプレッドシートへ保存する。
8. Botが確認と文字起こし結果を返す。

## リッチメニューのおすすめ構成

サイズはLINEの標準的な大サイズ `2500 x 1686` を想定します。

```text
┌──────────────────────────────┐
│        文字で記録             │
│   思いついたことをそのまま送る │
├──────────────────────────────┤
│        音声で記録             │
│   LINEのマイクで話して送る     │
├──────────────┬───────────────┤
│   一覧を見る   │    使い方       │
└──────────────┴───────────────┘
```

## LINE Official Account Managerで設定する場合

1. [LINE Official Account Manager](https://manager.line.biz/) を開く。
2. 対象の公式アカウントを選ぶ。
3. `トークルーム管理` → `リッチメニュー` を開く。
4. `作成` を押す。
5. テンプレートを選ぶ。
6. 各エリアに以下のアクションを設定する。

| エリア | アクション種別 | テキスト |
|---|---|---|
| 文字で記録 | テキスト | `文字で記録` |
| 音声で記録 | テキスト | `音声で記録` |
| 一覧を見る | テキスト | `一覧` |
| 使い方 | テキスト | `ヘルプ` |

## 実装済みのBot側コマンド

| 入力 | 動作 |
|---|---|
| `文字で記録` | 文章送信を案内 |
| `音声で記録` | LINEボイスメッセージ送信を案内 |
| 通常テキスト | 分類してSheets保存 |
| LINE音声メッセージ | Azure Speechで文字起こし、分類してSheets保存 |
| `一覧` | 直近7日を返信 |
| `ヘルプ` | 使い方案内 |

分類カテゴリ:

| 保存値 | 表示名 |
|---|---|
| `learned` | 学んだこと |
| `could_not` | できなかったこと |
| `next` | 次やりたいこと |
| `moyamoya` | モヤモヤしたこと |
| `other` | その他 |

## 注意点

- 音声の即時逐次表示はLIFF方式の方が向いています。
- LINE標準ボイスメッセージ方式は、送信後に文字起こしするため、リアルタイム表示はありません。
- 患者個人情報を話さない・書かない注意喚起は、リッチメニュー画像内にも小さく入れるのが安全です。
